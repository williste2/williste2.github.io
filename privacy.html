JOB_HUB – Privacy policy

JOB_HUB is a private tool used only by its owner on their own computer. There are no other users.

What data is accessed

With the owner's consent, JOB_HUB accesses the owner's own Gmail account through the Gmail API to send notifications to the owner and to read messages about the owner's own job applications.

How data is stored and used

  • Data is processed and stored only locally on the owner's computer.
  • Access tokens are kept in the operating system's credential store.
  • No data is sold, shared with third parties, or used for advertising.
  • JOB_HUB's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
